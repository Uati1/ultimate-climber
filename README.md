# Ultimate Climber landing

Short bilingual (PL/EN) landing for the climbing training app survey + waitlist.

## Stack

- Next.js + next-intl (PL/EN)
- Tailwind CSS
- Resend for signup notifications

## Run

```bash
npm install
cp .env.example .env.local
npm run dev
```
